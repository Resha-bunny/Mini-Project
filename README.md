
# Contact Directory

## Description
Contact Directory is a Python-based application that helps users manage their contacts.

## Features
- Add contact
- View contacts
- Search contact
- Delete contact

## Project Files

- person.py - Contains Person class
- contact.py - Contains Contact class
- contact_manager.py - Manages contacts
- main.py - Main program file

## Concepts Used

- Object-Oriented Programming (OOP)
- Classes and Objects
- Inheritance
- Functions
- Lists

## How to Run

Run the following command:

python main.py

# Mini-Project
The system can be improved in the future by adding a graphical user interface, login details and additional contact details features.
